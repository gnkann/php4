# Практична робота №4. PHP + PDO/MySQL

Варіант 1: Бібліотека (книги про Формулу-1).
CRUD для таблиці `books` через PDO з підготовленими запитами.

## Запуск
1. Виконати `schema.sql` (MySQL Workbench або консоль).
2. У `db.php` вказати свій пароль до бази.
3. `php -S localhost:8000` і відкрити http://localhost:8000
